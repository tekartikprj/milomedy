# Wav file backend for raw audio (tekartik_raw_audio_wav)

`tekartik_raw_audio_wav` implements the `tekartik_raw_audio` output API on top
of `package:wav`: instead of playing the frames you `feed` it, it accumulates
them in memory and hands them over as a `Wav` you can write to disk. It is a
recorder, not a player, and it is pure Dart (no platform channel).

## Guidelines

* Dependency (git, private repo, not on pub.dev):
  ```yaml
  dependencies:
    tekartik_raw_audio_wav:
      git:
        url: https://github.com/tekartikprj/milomedy
        path: packages/raw_audio_wav
  ```
  It brings `tekartik_raw_audio` (same repo, `path: packages/raw_audio`) and
  `package:wav`. Add `wav: '>=1.5.0'` to your own dependencies only if you
  name the `Wav` type explicitly: `raw_audio_wav.dart` re-exports
  `raw_audio.dart`, not `package:wav/wav.dart`.
* One import, `package:tekartik_raw_audio_wav/raw_audio_wav.dart`: it gives
  `RawAudioManagerWav`, `RawAudioOutputWav` and, through the re-export, the
  whole `tekartik_raw_audio` API (`RawAudioData`, `RawAudioManager`,
  `RawAudioOutput`, `RawAudioOutputOptions`, `RawAudioOutputFeedOptions`,
  `Uint8List`). The `tekartik-raw-audio-output` skill of `tekartik_raw_audio`
  documents that shared API.
* Usage is always the same three steps: `var manager = RawAudioManagerWav();`
  `var output = manager.createOutput(options: RawAudioOutputOptions(
  sampleRate: 44100, channelCount: 1));` then `await output.feed(data)` as
  often as needed and `output.wav` at the end. Keep the variable typed as
  `RawAudioManagerWav` / `RawAudioOutputWav`: the `wav` getter only exists on
  this backend, a `RawAudioOutput` reference needs a cast. There is no public
  constructor for `RawAudioOutputWav`, always go through `createOutput`.
* `output.wav` builds a fresh `package:wav` `Wav` from everything fed so far
  (`Wav(channels, options.sampleRate)`, always `WavFormat.pcm16bit`). Write it
  with `wav.write()` (`Uint8List`) or `await wav.writeFile(path)`, or inspect
  `wav.channels` (one `Float64List` per channel, samples in `[-1, 1]`),
  `wav.duration` and `wav.toMono()`. Reading the getter rebuilds and
  reallocates everything: call it once, at the end.
* Byte order is the one real trap. The backend decodes the bytes you feed as
  **little-endian** pcm16 (wav's own order) and writes them back untouched,
  but `RawAudioData.fromInt16List(samples)` packs **big-endian**, and so do
  `pcm16GenerateSineWaveAudioData` / `pcm16GenerateExampleAudioData` from
  `package:tekartik_raw_audio/generator.dart`. Feeding those straight into
  this backend produces a file whose samples are byte swapped — a clean sine
  in the bytes, noise in a player. Build the bytes yourself with
  `ByteData.setInt16(offset, value, Endian.little)` +
  `RawAudioData.fromChannelsBytes(channelsBytes: [bytes])`, or swap the
  generated bytes before feeding them (see the examples).
* One `Uint8List` per channel, 2 bytes per frame, planar (not interleaved):
  `channelsBytes[0]` is the left channel, `[1]` the right. `feed` reads
  exactly `options.channelCount` entries and throws `RangeError` when mono
  data is fed to a stereo output. Keep every channel the same length: the
  frame count of the resulting `Wav` is taken from the first channel and a
  shorter one overruns.
* `play()` and `stop()` are inherited no-ops (nothing is audible) and a
  `RawAudioOutputFeedOptions.onFeed` callback is never called by this
  backend: there is no queue to refill, `feed` just appends. Every frame fed
  stays in memory until the output is dropped, so split long captures into
  several outputs/files.
* This package only writes. To read a wav file back use `package:wav`
  directly (`Wav.read(bytes)`, `await Wav.readFile(path)`), or the
  `tekartik_wav` package for an incremental pure-Dart pcm16 reader and mixer.
* Same-code-everywhere pattern: write the generating code against
  `RawAudioManager` / `RawAudioOutput`, pass `RawAudioManagerWav()` in a test
  or a CLI to capture a reference file, and the real backend
  (`tekartik_raw_audio_pcm_sound` on Flutter) in the app.
* Tests: `dart test`. Asserting on `output.wav.write()` bytes is the easiest
  check (see `test/raw_audio_wav_test.dart`, which uses `parseHexString` from
  `package:tekartik_common_utils/hex_utils.dart`).

## Examples

### Capture generated frames into a wav file

```dart
import 'dart:math' as math;
import 'dart:typed_data';

import 'package:tekartik_raw_audio_wav/raw_audio_wav.dart';

/// Little endian pcm16 bytes, the order this backend expects.
Uint8List pcm16LeBytes(List<int> samples) {
  var bytes = Uint8List(samples.length * 2);
  var byteData = ByteData.view(bytes.buffer);
  for (var i = 0; i < samples.length; i++) {
    byteData.setInt16(i * 2, samples[i], Endian.little);
  }
  return bytes;
}

Future<void> main() async {
  const sampleRate = 44100;
  var manager = RawAudioManagerWav();
  var output = manager.createOutput(
    options: RawAudioOutputOptions(sampleRate: sampleRate, channelCount: 1),
  );

  // 1 second of 440Hz, fed in 100ms chunks.
  const chunkFrames = sampleRate ~/ 10;
  for (var chunk = 0; chunk < 10; chunk++) {
    var samples = <int>[];
    for (var i = 0; i < chunkFrames; i++) {
      var t = (chunk * chunkFrames + i) / sampleRate;
      samples.add((32767 * 0.3 * math.sin(2 * math.pi * 440 * t)).round());
    }
    await output.feed(
      RawAudioData.fromChannelsBytes(channelsBytes: [pcm16LeBytes(samples)]),
    );
  }

  var wav = output.wav;
  print('${wav.duration}s, ${wav.channels.length} channel(s)');
  await wav.writeFile('.local/sine.wav');
}
```

### Feeding the tekartik_raw_audio generators (byte swap needed)

```dart
import 'dart:typed_data';

import 'package:tekartik_raw_audio/generator.dart';
import 'package:tekartik_raw_audio_wav/raw_audio_wav.dart';

/// The generators and RawAudioData.fromInt16List pack big-endian pcm16,
/// this backend reads little-endian: swap every sample's 2 bytes.
RawAudioData swapEndian(RawAudioData data) {
  return RawAudioData.fromChannelsBytes(
    channelsBytes: data.channelsBytes.map((bytes) {
      var swapped = Uint8List(bytes.length);
      for (var i = 0; i + 1 < bytes.length; i += 2) {
        swapped[i] = bytes[i + 1];
        swapped[i + 1] = bytes[i];
      }
      return swapped;
    }).toList(),
  );
}

Future<void> main() async {
  // The generators are mono: create a one channel output.
  var output = RawAudioManagerWav().createOutput(
    options: RawAudioOutputOptions(sampleRate: 44100, channelCount: 1),
  );
  await output.feed(swapEndian(pcm16GenerateExampleAudioData()));
  await output.feed(
    swapEndian(pcm16GenerateSineWaveAudioData(periods: 440, freq: 440)),
  );
  await output.wav.writeFile('.local/scale.wav');
}
```

### Stereo capture, and looking at the decoded samples

```dart
import 'dart:typed_data';

import 'package:tekartik_raw_audio_wav/raw_audio_wav.dart';
import 'package:wav/wav.dart';

Uint8List pcm16LeBytes(List<int> samples) {
  var bytes = Uint8List(samples.length * 2);
  var byteData = ByteData.view(bytes.buffer);
  for (var i = 0; i < samples.length; i++) {
    byteData.setInt16(i * 2, samples[i], Endian.little);
  }
  return bytes;
}

Future<Wav> stereoWav(List<int> left, List<int> right) async {
  // Both channels must have the same number of frames.
  assert(left.length == right.length);
  var output = RawAudioManagerWav().createOutput(
    options: RawAudioOutputOptions(sampleRate: 22050, channelCount: 2),
  );
  await output.feed(
    RawAudioData.fromChannelsBytes(
      channelsBytes: [pcm16LeBytes(left), pcm16LeBytes(right)],
    ),
  );
  return output.wav;
}

Future<void> main() async {
  var wav = await stereoWav([0, 16384, 0, -16384], [0, -16384, 0, 16384]);
  print(wav.channels.first); // ~[0.0, 0.5, 0.0, -0.5], pcm16 scaled to [-1, 1]
  print(wav.samplesPerSecond); // 22050
  var bytes = wav.write();
  print('${bytes.length} bytes'); // 44 header + 16 data
}
```

### Test the bytes that come out

```dart
import 'package:tekartik_common_utils/hex_utils.dart';
import 'package:tekartik_raw_audio_wav/raw_audio_wav.dart';
import 'package:test/test.dart';

void main() {
  test('fed bytes end up in the data chunk untouched', () async {
    var output = RawAudioManagerWav().createOutput(
      options: RawAudioOutputOptions(sampleRate: 1, channelCount: 1),
    );
    await output.feed(
      RawAudioData.fromChannelsBytes(
        channelsBytes: [
          Uint8List.fromList([1, 2]),
        ],
      ),
    );
    expect(
      output.wav.write(),
      parseHexString('''
      52 49 46 46  26 00 00 00  57 41 56 45  66 6D 74 20
      10 00 00 00  01 00 01 00  01 00 00 00  02 00 00 00
      02 00 10 00  64 61 74 61  02 00 00 00  01 02
    '''),
    );
  });
}
```
